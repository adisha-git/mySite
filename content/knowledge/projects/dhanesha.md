# Dhanesha Chemicals & Fertilisers — Built for a friend

In progress · https://www.dhaneshachemicalsandfertilisers.com/

## What it is

Dhanesha Chemicals & Fertilisers is a fast, SEO-focused catalogue website Adisha is building for a friend's fertiliser and agri-chemicals supply business in Sri Lanka. It is still in progress.

The stack includes Next.js, React, TypeScript, Tailwind CSS and JSON-LD structured data for SEO. It is hosted on Vercel.
