# Sri Aero — Built for a friend

Live at https://www.sriaero.ca/

## What it is

Sri Aero is the website Adisha built for a friend's mobile aircraft-detailing business in Calgary, Canada. It covers the business's services and fleet, takes quote requests, and uses hand-built SVG animation.

The stack includes Next.js, React, TypeScript, Tailwind CSS, Framer Motion, SVG animation and JSON-LD structured data for SEO. It is hosted on Vercel.
