# Adisha Madhushanka — Building websites with Next.js and a headless CMS

How Adisha builds websites: Next.js and React front ends, content from a headless or custom CMS, and SEO designed in from the start, with WordPress as one option in a wider toolkit.

## Website development: what kind of websites he builds

For website development, whether a business website, a company site or a catalogue site, Adisha's work centres on Next.js and React front ends, with content coming from a headless or custom CMS and search visibility designed into the build. For a new website, Next.js and React are where he starts, and the CMS is chosen to suit the project.

He builds sites with a headless or custom CMS, where content is served through APIs to Next.js and React front ends. The content is managed in the CMS, and the front end renders it.

## Headless and custom CMS architecture

In a headless setup, the CMS holds the content and serves it through an API, and a Next.js or React front end renders the pages. This keeps editing in the CMS while the front end stays fast and fully under the developer's control.

He designs the content model so the people who own the content can edit it themselves without help from a developer.

He chooses the CMS for each project rather than defaulting to one. A headless CMS, a custom CMS, or a traditional WordPress site can each be the right call, depending on the project's performance needs, how the content will be edited, and the budget.

## Rendering strategies in Next.js

Adisha works with the rendering strategies Next.js offers and chooses the right one for each page:

- Server-side rendering (SSR) for pages that need fresh data on every request.
- Static site generation (SSG) for pages whose content rarely changes, so they can be served from a CDN.
- Incremental static regeneration (ISR) for static pages that need to refresh when content changes, without rebuilding the whole site.
- React Server Components to render on the server and send less JavaScript to the browser.
- Client-side rendering for the interactive parts of a page.

## Technical SEO built into the architecture

Adisha builds SEO into the architecture of a site rather than adding it afterwards. That covers server-rendered HTML that search engines can read, metadata and Open Graph tags, structured data and schema markup, sitemaps, canonical URLs, and performance against Core Web Vitals. Sri Aero and Dhanesha both use JSON-LD structured data.
