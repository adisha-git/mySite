## About MindLogics

## What I owned

At MindLogics, Adisha worked on a Visa Workflow Management System built with TypeScript and React.js. The tool manages the visa documentation process: users upload passports and supporting documents, and the system identifies each document's type and extracts the relevant information, reducing manual data entry.

The team delivered the system. Adisha's contribution was helping to design and set up the frontend architecture, organising the project structure, developing reusable base components and contributing to the core workflow. He also worked with Amazon Textract and Amazon Bedrock on document data extraction.

More broadly, he developed and maintained scalable web applications using React.js, Next.js, Node.js, Express.js, JavaScript, TypeScript, HTML and CSS. He built reusable React components and integrated frontend applications with RESTful APIs.

## AI document processing in the Visa Workflow system

It uses Amazon Textract for OCR and document extraction, and Anthropic Claude through Amazon Bedrock to interpret document content and organise the extracted information into structured fields.
